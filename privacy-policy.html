Política de Privacidade

Última atualização: abril de 2026

Esta Política de Privacidade descreve como a extensão Slow Hostel Assist trata as informações durante o seu uso. A extensão foi desenvolvida para uso interno da equipe do Slow Hostel e não é destinada ao público geral.

1. Quem desenvolve esta extensão

A extensão é mantida pela equipe do Slow Hostel para uso operacional interno. Dúvidas podem ser enviadas para dev.juliadosanjos@gmail.com.

2. Quais dados são acessados

A extensão lê o conteúdo visível das páginas do sistema HQBeds (admin.hqbeds.com.br) — especificamente textos de reservas, datas, tipos de acomodação e listas de ocupação — para gerar automaticamente templates de mensagens para WhatsApp.

Esses dados incluem informações como:

  • Nomes de hóspedes e datas de check-in/check-out exibidos na tela do HQBeds
  • Tipo de quarto e quantidade de hóspedes
  • Dados de ocupação para a lista de café da manhã

3. O que fazemos com esses dados

Os dados lidos são utilizados exclusivamente para montar o texto do template no popup da extensão. Todo o processamento ocorre localmente no navegador do usuário.

  • Nenhum dado é enviado para servidores externos.
  • Nenhum dado é armazenado pela extensão (em disco, banco de dados ou nuvem).
  • Nenhum dado é compartilhado com terceiros.
  • Os dados existem apenas na memória do navegador durante o uso do popup e são descartados ao fechar.

4. Permissões utilizadas e por quê

  • activeTab — necessária para identificar a aba ativa do HQBeds antes de injetar o script de leitura.
  • scripting — necessária para injetar as funções de leitura do DOM nas páginas do HQBeds e capturar os dados exibidos na tela.
  • clipboardWrite — necessária para copiar o template gerado para a área de transferência, facilitando o envio pelo WhatsApp.
  • Host permission (admin.hqbeds.com.br) — a extensão opera exclusivamente neste domínio. Nenhum outro site é acessado.

5. Armazenamento e retenção

A extensão não utiliza localStorage, chrome.storage, cookies ou qualquer mecanismo de persistência de dados. Ao fechar o popup, todos os dados processados são descartados.

6. Compartilhamento com terceiros

A extensão não compartilha dados com nenhum terceiro. Não utiliza serviços de analytics, rastreamento, publicidade ou APIs externas.

7. Segurança

Como os dados não saem do navegador do usuário e não são armazenados, o risco de exposição é mínimo. A extensão opera apenas no sistema interno do Slow Hostel (HQBeds), acessível somente por colaboradores autenticados.

8. Alterações nesta política

Esta política pode ser atualizada conforme a extensão evolui. A data de última atualização sempre será indicada no topo deste documento.

9. Contato

Em caso de dúvidas sobre esta política, entre em contato pelo e-mail dev.juliadosanjos@gmail.com.
